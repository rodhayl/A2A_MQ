## 2. Defects Identified and Fixed

Six concrete defects were identified, deterministic reproductions established, root causes fixed, and tests added/adjusted across cohesive commits:

1. **`deploy/production/generate.py:103` Syntax Error (`3ba3216`):**
   - *Symptom:* `SyntaxError: unmatched '}'` in `deploy/production/generate.py:103` inside `deployment()` crashed AST compilation and prevented test collection for `tests/test_production_deployment.py`.
   - *Fix:* Removed stray closing brace in `generate.py` and extended `tools/check.py` to check AST syntax across `deploy/`, `scripts/`, and `tools/` in addition to `src/` and `tests/`.

2. **`tests/test_task_api.py` Physical Storage Flake (`26f8205`):**
   - *Symptom:* `TaskAPI` fixture set `wait_timeout=.2` (200ms). On physical ext4 storage where synchronous SQLite transactions take ~200ms to fsync, tests flaked with premature `TASK_API_TIMEOUT`.
   - *Fix:* Increased fixture wait and stream timeouts to 5.0s.

3. **`tests/test_local_native_versions.py` Logic Defect (`c25bcb4`):**
   - *Symptom:* `test_digest_tamper_fails` wrote 8 bytes (`b"tampered"`) instead of 5 bytes (matching `b"daprd"`), causing binary size check to trigger before digest mismatch verification.
   - *Fix:* Aligned tampered binary size with manifest length and added an explicit size-tampering negative test.

4. **Missing Imports in `backup.py` and `test_operations_v2.py` (`e4a1692`):**
   - *Symptom:* `src/a2a_mq/backup.py:19` used `require` without importing it from `.domain`; `tests/test_operations_v2.py:54` referenced `PermanentError` without importing it.
   - *Fix:* Imported `require` in `backup.py` and `PermanentError` in `test_operations_v2.py`.

5. **`src/a2a_mq/application.py` Crypto Validation Order (`bf8713b`):**
   - *Symptom:* `_protectors()` called `token_provider()` (which attempts to read `tokenFile`) before validating the schema of `command` and `event` route configs. An invalid route config with missing key fields raised `SECRET_UNAVAILABLE` instead of `INVALID_CRYPTO_CONFIG`. Also, `test_application_new.py` used tight 2s timeouts for asynchronous state transitions that exceeded ext4 commit latencies under load.
   - *Fix:* Moved route configuration dictionary and key schema validation before secret token inspection, and bounded test loop timeouts to 10s.

6. **CI Contract and Service Test Alignment (`3415b10`):**
   - *Symptom:* Commit `1d4bbc00` had removed step IDs (`id: tests`, `id: junit`, `id: evidence`) from `.github/workflows/ci.yml` breaking `tests/test_ci_contract.py`; commit `04547362` had exempted `/health/ready` from app-token authentication but `tests/test_service.py` still asserted 401 for `/health/ready`; `test_service.py` accessed `bus.client.is_closed` after `bus.close()` set `bus.client = None`; `tests/test_mcp_tools_new.py` and `test_bridge_sdk.py` had tight 0.1-0.2s `wait_timeout`s in `TaskAPI`.
   - *Fix:* Restored workflow step IDs, updated dependency check assertions in `test_ci_contract.py` to allow `mcp` extra, updated `test_service.py` to expect 200 on unauthenticated `/health/ready` and check `bus._closed`, and increased `TaskAPI` wait timeouts to 5.0s.

# Documentation archive

Superseded project material is preserved here for traceability.

- `planning/`: early research, implementation/test plans and MVP planning.
- `handoffs/`: old agent prompts and machine-specific follow-up instructions.
- `reference/`: superseded reference-service documentation.
- `validation/`: historical phase, audit, resource, resilience and local
  certification records.

Archive files are not current release documentation. Counts, availability statements,
resource measurements and SHA claims remain bound to the date/SHA inside each file.

Use [../STATUS.md](../STATUS.md) and [../VALIDATION.md](../VALIDATION.md) for current
v0.1.0-rc2 state.

# Architecture Decision Records

ADRs preserve decisions and their original context. They are not rewritten merely
because implementation progressed later, so individual ADRs may contain historical
status language.

For current state use:

- [../STATUS.md](../STATUS.md)
- [../ARCHITECTURE.md](../ARCHITECTURE.md)
- [../VALIDATION.md](../VALIDATION.md)

New contract-changing architectural decisions should receive a new ADR.
